# spinning-cat-3d

A playful 3D spinning cat that follows the mouse pointer.

## Run it locally

Because the project uses a browser module import from a CDN, you can open `index.html` directly in a browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — page shell
- `style.css` — styling and layout
- `script.js` — Three.js 3D cat scene and animation
